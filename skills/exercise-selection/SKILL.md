## Exercise selection

- **Swap within the pattern.** Replace a vertical pull with a vertical pull, a lateral raise with a
  lateral raise. The `pattern` field groups them. Cross patterns only for a stated reason (pain,
  a muscle that's under-trained) and say so.
- **Only the allowed list.** You are given the exercises that fit every rule (equipment, knee, one
  cable). Anything else fails the rules check.
- **Dumbbells first** (the person prefers them), then machines, then the single cable.
- **Priorities** (from the profile): lats, chest, shoulders (side delts), biceps, back, lower back.
  When adding sets or exercises, favour these.
- **Keep the session the same length.** A swap should have similar sets and rest. Adding an exercise
  usually means removing one or cutting a set elsewhere to stay inside 35–45 minutes and ~5 exercises.
- **Trial exercises** ("(knee test)") are on probation: any pain means remove them, not replace them
  with something similar that loads the same way.
- **Starting weight for a new exercise:** leave `weight` empty (the person finds it in the first
  session) unless a similar exercise in the plan gives a clear anchor; then go conservative.
